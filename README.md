# CuraCloud - Multi-Tenant Hospital Management System (SaaS)

Frontend application built with **React.js (Vite)** and **Material UI (MUI)** featuring **Feature-Based Folder Structure** and **Role-Based Access Control (RBAC)**.

---

## 🚀 Quick Start Guide

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the Development Server
```bash
npm run dev
```

The application will start on **`http://localhost:3000`**.
